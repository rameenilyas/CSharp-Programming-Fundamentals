# Module 5: User Input & Output — Exercises

## Exercise 1: Personal Introduction

Create a C# program that:

1. Takes the user's name as input.
2. Takes the user's age as input.
3. Takes the user's city as input.
4. Displays the information in a clean format.

---

## Exercise 2: Number Information

Create a C# program that:

1. Takes two integer numbers from the user.
2. Displays both numbers.
3. Displays their sum.

---

## Exercise 3: Student Details

Create a C# program that takes:

- Student Name
- Roll Number
- Marks

Then display the information using **string interpolation**.

---

## Exercise 4: Product Details

Create a C# program that takes:

- Product Name
- Quantity
- Price

Then display all information using a properly formatted output.

---

## Exercise 5: Simple Profile

Create a C# program that takes:

- Name
- Age
- City
- Favorite Color

Then display a formatted profile using string interpolation.

---

## Exercise 6: Two Numbers

Create a C# program that takes two numbers and displays:

- First Number
- Second Number
- Sum
- Difference

Use `Console.ReadLine()` for input and `Convert.ToInt32()` for integer conversion.

---

## Exercise 7: Subject Marks

Create a C# program that takes marks for three subjects:

- English
- Mathematics
- Computer

Then display all three marks in a formatted output.

---

## Exercise 8: Employee Information

- Employee Name

- Age
- Salary

Then display the information using string interpolation.

---

## Exercise 9: Rectangle Information

- Length
- Width

Then display:

- Length
- Width
- Area

Use formatted output.

---

## Exercise 10: Shopping Information

Create a C# program that takes:

- Product Name
- Quantity
- Price

Then display a formatted shopping summary.

```text

Product: Laptop
Quantity: 2
Price: 50000
````
