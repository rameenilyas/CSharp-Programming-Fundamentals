

### Module 6: Decision Making — Assignment

#### Task 1 — Positive, Negative, or Zero

Create a C# program that:

1. Takes an integer as input.
2. Checks whether the number is positive, negative, or zero.
3. Displays the appropriate result.

Use `if-else if-else`.

#### Task 2 — Pass or Fail

Create a C# program that:

1. Takes marks as input.
2. If marks are 50 or above, display `"Pass"`.
3. Otherwise, display `"Fail"`.

Use `if-else`.

#### Task 3 — Grade Calculator

Create a C# program that takes marks as input and displays:

* `80–100` → A Grade
* `70–79` → B Grade
* `60–69` → C Grade
* `50–59` → D Grade
* Below `50` → Fail

Use `else if`.

#### Task 4 — Age Category

Create a C# program that takes age as input and displays:

* Below 13 → Child
* 13–19 → Teenager
* 20–59 → Adult
* 60 or above → Senior

Use `else if`.

#### Task 5 — Largest of Two Numbers

Create a C# program that:

1. Takes two numbers as input.
2. Compares both numbers.
3. Displays the larger number.
4. If both numbers are equal, display `"Both numbers are equal"`.

Use `if-else`.

#### Task 6 — Login Verification

Create a C# program that:

1. Creates a `bool` variable named `isLoggedIn`.
2. Checks whether the user is logged in.
3. If `true`, display `"Welcome!"`.
4. Otherwise, display `"Please login first."`

Use `if-else`.

#### Task 7 — Nested Login Check

Create a C# program that:

1. Takes age as input.
2. Checks whether the user is 18 or older.
3. Inside the first `if`, check whether the user has an ID.
4. If both conditions are true, display `"Entry allowed."`
5. Otherwise, display an appropriate message.

Use **Nested `if`**.

#### Task 8 — Day of the Week

Create a C# program that:

1. Takes a number from `1` to `7`.
2. Uses `switch`.
3. Displays the corresponding day:

   * `1` → Monday
   * `2` → Tuesday
   * `3` → Wednesday
   * `4` → Thursday
   * `5` → Friday
   * `6` → Saturday
   * `7` → Sunday
4. Use `default` for an invalid number.
