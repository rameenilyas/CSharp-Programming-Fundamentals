# 📘 02. Comments in C#

## 📖 Definition

Comments are used to explain the code. They make the program easier to understand. The compiler ignores comments during execution.

---

## Types of Comments

### 1. Single-Line Comment

```csharp
// This is a single-line comment
```

### 2. Multi-Line Comment

```csharp
/*
This is a
multi-line comment
*/
```

---

## Example

```csharp
using System;

// Program to demonstrate comments

class Program
{
    static void Main(string[] args)
    {
        // Display a message
        Console.WriteLine("Hello, World!");
    }
}
```

---

## 🎯 Key Points

- Comments improve code readability.
- They help other programmers understand the code.
- The compiler ignores comments.
- Comments do not affect program execution.

---

## 📌 Exam Definition

Comments are explanatory notes in a program that are ignored by the compiler during execution.
