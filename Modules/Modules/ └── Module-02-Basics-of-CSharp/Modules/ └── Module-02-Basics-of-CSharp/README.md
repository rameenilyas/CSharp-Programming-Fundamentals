
# 📘 Module 2 – Basics of C#

Welcome to **Module 2** of the C# Programming Fundamentals course.

## 📚 Topics Covered

- Structure of a C# Program
- Using System
- Namespace
- Main() Method
- Comments
- Input and Output
- Escape Sequences

## 🎯 Learning Objectives

After completing this module, you will be able to:

- Understand the basic structure of a C# program.
- Use `using System` and `namespace`.
- Write code inside the `Main()` method.
- Add single-line and multi-line comments.
- Take input using `Console.ReadLine()`.
- Display output using `Console.Write()` and `Console.WriteLine()`.
- Use escape sequences such as `\n` and `\t`.
