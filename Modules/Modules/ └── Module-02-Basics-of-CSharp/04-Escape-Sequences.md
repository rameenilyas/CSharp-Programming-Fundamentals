# 📘 04. Escape Sequences in C#

## 📖 Definition

Escape sequences are special characters used to format the output.

---

## Common Escape Sequences

| Escape Sequence | Description |
|-----------------|-------------|
| `\n` | Moves the cursor to the next line |
| `\t` | Inserts a horizontal tab |
| `\"` | Prints double quotation marks |
| `\\` | Prints a backslash |

---

## Example 1

```csharp
Console.WriteLine("Hello\nWorld");
```

### Output

```
Hello
World
```

---

## Example 2

```csharp
Console.WriteLine("Name\tAge");
Console.WriteLine("Ali\t20");
```

### Output

```
Name    Age
Ali     20
```

---

## 🎯 Key Points

- `\n` moves to the next line.
- `\t` adds tab spacing.
- Escape sequences improve output formatting.

---

## 📌 Exam Definition

Escape sequences are special characters that control the formatting of the output.
