# Module 4: Operators

This module covers different types of operators in C#.

## Topics Covered

- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Logical Operators
- Increment and Decrement Operators

## Concepts

### Arithmetic Operators
`+  -  *  /  %`

### Assignment Operators
`=  +=  -=`

### Comparison Operators
`==  !=  >  <  >=  <=`

### Logical Operators
`&&  ||  !`

### Increment / Decrement
`++  --`
