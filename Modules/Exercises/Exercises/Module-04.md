# Module 4: Operators — Exercises

## Exercise 1: Arithmetic Operators

Create a C# program that takes two numbers and displays:

- Addition
- Subtraction
- Multiplication
- Division
- Remainder

---

## Exercise 2: Comparison Operators

Create a program that compares two numbers using:

- `==`
- `!=`
- `>`
- `<`
- `>=`
- `<=`

Display the result as `True` or `False`.

---

## Exercise 3: Logical Operators

Create a program using:

- `&&` AND
- `||` OR
- `!` NOT

Test different conditions and display the results.

---

## Exercise 4: Increment and Decrement

Create a program that:

1. Creates an integer variable.
2. Uses `++` to increase its value.
3. Uses `--` to decrease its value.
4. Displays the results.

---

## Exercise 5: Rectangle Properties

Create a program that calculates:

- Area of a rectangle
- Perimeter of a rectangle

Formula:

**Area = length × width**

**Perimeter = 2 × (length + width)**
