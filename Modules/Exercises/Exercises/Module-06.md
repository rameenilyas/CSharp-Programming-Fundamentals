Module 6: Decision Making — Quiz
Question 1

When does the code inside an if statement execute?

A. When the condition is true
B. When the condition is false
C. Every time the program runs
D. Only after taking input

Answer: A. When the condition is true

Question 2

If an if condition is false and an else block is present, which block executes?

A. The if block
B. The else block
C. Both blocks
D. Neither block

Answer: B. The else block

Question 3

Which statement is commonly used to check multiple conditions in sequence?

A. else if
B. break
C. default
D. switch only

Answer: A. else if

Question 4

What will be the output?

int marks = 75;


if (marks >= 80)
{
    Console.WriteLine("A Grade");
}
else if (marks >= 70)
{
    Console.WriteLine("B Grade");
}
else
{
    Console.WriteLine("C Grade");
}

A. A Grade
B. B Grade
C. C Grade
D. No output

Answer: B. B Grade

Question 5

What does a Nested if mean?

A. An if statement outside a class
B. An if statement inside another if statement
C. Two else statements together
D. An if statement without a condition

Answer: B. An if statement inside another if statement

Question 6

When is an inner if checked in a nested if structure?

A. Before the outer if
B. When program execution reaches the inner if inside the outer block
C. Only when the outer condition is false
D. Never

Answer: B. When program execution reaches the inner if inside the outer block

Question 7

Which keyword is commonly used to stop execution of a matching switch case?

A. continue
B. stop
C. exit
D. break

Answer: D. break

Question 8

When does the default block in a switch statement execute?

A. When the first case matches
B. When no case matches
C. After every case
D. Only for case 1

Answer: B. When no case matches

Question 9

What will be the output?

int day = 2;


switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;


    case 2:
        Console.WriteLine("Tuesday");
        break;


    case 3:
        Console.WriteLine("Wednesday");
        break;
}

A. Monday
B. Tuesday
C. Wednesday
D. Invalid day

Answer: B. Tuesday

Question 10

What is the main difference between if and switch?

A. if can evaluate conditions, while switch matches cases
B. if is only used with numbers
C. switch cannot have multiple cases
D. Both have exactly the same syntax

Answer: A. if can evaluate conditions, while switch matches cases
