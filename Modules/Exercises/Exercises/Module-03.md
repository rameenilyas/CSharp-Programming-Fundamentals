# Module 3: Variables & Data Types — Exercises

## Exercise 1: Variables

Create variables to store:

- Your name
- Your age
- Your city

Print all three values using `Console.WriteLine()`.

---

## Exercise 2: Constants

Create a constant named `PI` with the value `3.14`.

Print its value.

---

## Exercise 3: Data Types

Create variables using the following data types:

- int
- float
- double
- char
- bool
- string

Assign suitable values to each variable and print them.

---

## Exercise 4: Student Information

Create a C# program that stores:

- Student name
- Age
- Marks
- Grade
- IsPassed

Use appropriate data types and display all information.

---

## Exercise 5: Variable Naming

Identify which variable names are valid and which are invalid:

```text
age
studentName
1marks
student-name
city
student name
_marks
````

---

## Exercise 6: Constant vs Variable

Create:

* A variable `age`
* A constant `DAYS_IN_WEEK`

Assign suitable values and print both.

---

## Exercise 7: Complete Program

Write a C# program that uses all of the following:

```text
int
float
double
char
bool
string
```

Display all values using `Console.WriteLine()`.
