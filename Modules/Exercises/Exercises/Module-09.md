Module 09: Functions in C# Quiz

1. Which keyword is used when a C# function does not return a value?
   A. empty
   B. void
   C. none
   D. null

2. What must you do to execute a function after defining it?
   A. Rename the function
   B. Call the function
   C. Delete the function
   D. Add another class

3. In static void GreetUser(string name), what is name?
   A. Return value
   B. Class
   C. Parameter
   D. Argument

4. Given static int Add(int a, int b) { return a + b; }, what is returned by Add(10, 20)?
   A. 10
   B. 30
   C. 20
   D. 200

5. Which statement sends a value back from a function?
   A. return
   B. continue
   C. break
   D. using

6. What is the argument in GreetUser("Rameen")?
   A. GreetUser
   B. "Rameen"
   C. name
   D. string

7. Which function correctly returns the square of a number?
   A. static int Square(int n) { return n * n; }
   B. static int Square(int n) { Console.WriteLine(n); }
   C. static void Square(int n) { return n * n; }
   D. static int Square(int n) { return n + n; }

8. Given CheckEvenOdd(8), and the function checks number % 2 == 0, what should it display?
   A. Odd
   B. Zero
   C. Error
   D. Even

9. Which statement about parameters and arguments is correct?
   A. A parameter is always a return value.
   B. A parameter is declared in the function; an argument is supplied when calling it.
   C. An argument must always be a function name.
   D. Parameters can only be strings.

10. Given static int Square(int number) { return number * number; }, what is stored in result after int result = Square(5);?
   A. 5
   B. 0
   C. 10
   D. 25
