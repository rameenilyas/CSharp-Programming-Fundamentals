## Quiz

### Question 1
What is mainly used to create patterns in C#?

- A) Variables
- B) Nested Loops
- C) Methods
- D) Arrays

**Answer:** B) Nested Loops

---

### Question 2
What does the outer loop usually control?

- A) Columns
- B) Characters
- C) Rows
- D) Spaces

**Answer:** C) Rows

---

### Question 3
What does the inner loop usually control?

- A) Items in each row
- B) Number of programs
- C) Class name
- D) User input

**Answer:** A) Items in each row

---

### Question 4
What does `Console.Write()` do?

- A) Moves to the next line
- B) Prints on the same line
- C) Stops the program
- D) Creates a loop

**Answer:** B) Prints on the same line

---

### Question 5
What does `Console.WriteLine()` do?

- A) Moves to the next line
- B) Stops the loop
- C) Deletes output
- D) Creates a variable

**Answer:** A) Moves to the next line

---

### Question 6
What is the output of this code?

```csharp
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= i; j++)
    {
        Console.Write("*");
    }

    Console.WriteLine();
}
````

* A)

```text
***
***
***
```

* B)

```text
*
**
***
```

* C)

```text
***
**
*
```

* D)

```text
*
*
*
```

**Answer:** B) `*`, `**`, `***`

---

### Question 7

Which condition is commonly used for an increasing triangle?

* A) `j >= i`
* B) `j == i`
* C) `j <= i`
* D) `j > i`

**Answer:** C) `j <= i`
