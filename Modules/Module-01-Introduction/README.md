# 📘 Module 1: Introduction to Programming

## 🎯 Learning Objectives

After completing this module, you will be able to:

- Understand what programming is.
- Differentiate between a Program and Programming.
- Understand Algorithms.
- Draw Flowcharts.
- Write Pseudocode.
- Learn the basics of programming logic.

---

# 1️⃣ Programming

## Definition

Programming is the process of writing instructions for a computer to perform a specific task.

### Examples

- Calculator
- WhatsApp
- Chrome
- Microsoft Word
- Instagram
- ATM Software
- Hospital Management System

---

# 2️⃣ Program

## Definition

A program is a collection of instructions written to perform a specific task.

---

# 3️⃣ Programmer

## Definition

A programmer is a person who writes, tests, and maintains computer programs.

---

# 4️⃣ Algorithm

## Definition

An algorithm is a step-by-step procedure to solve a problem.

### Characteristics

- Clear
- Simple
- Finite
- Logical

### Example

**Tea Making Algorithm**

1. Start
2. Boil water
3. Add tea leaves
4. Add sugar
5. Add milk
6. Boil for 2 minutes
7. Pour into cup
8. Stop

---

# 5️⃣ Flowchart

## Definition

A flowchart is a graphical representation of an algorithm using symbols.

### Common Symbols

| Symbol | Meaning |
|--------|---------|
| Oval | Start / End |
| Rectangle | Process |
| Parallelogram | Input / Output |
| Diamond | Decision |
| Arrow | Flow of Control |

---

# 6️⃣ Pseudocode

## Definition

Pseudocode is an informal way of writing program logic using simple English statements.

### Example

```text
START
Input Number
IF Number > 0
    PRINT "Positive"
ELSE
    PRINT "Negative"
END IF
STOP
```

---

# 💡 Key Points

- Programming means writing instructions for computers.
- A Program is a collection of instructions.
- An Algorithm is a step-by-step solution.
- A Flowchart represents an algorithm graphically.
- Pseudocode represents logic in simple English.
