# Module 3 Project: Student Profile System

## Description

A simple C# console program that stores and displays student information using variables and different data types.

## Concepts Used

- Variables
- Constants
- int
- float
- double
- char
- bool
- string

## Student Information

The program stores:

- Student Name
- Age
- City
- Marks
- Grade
- Passed Status

## Expected Output

```text
===== Student Profile =====

Name: Ali
Age: 20
City: Karachi
Marks: 85.5
Grade: A
Passed: TrueLearning Objective

This project helps beginners understand how variables and different C# data types are used in a real program.
