
# Student Result & Grade Calculator

## Project Question

Create a C# console application called **Student Result & Grade Calculator**.

The program should:

1. Ask the user to enter the student's name.
2. Take marks for five subjects as input.
3. Calculate the total marks.
4. Calculate the student's percentage.
5. Assign a grade according to the percentage.
6. Check whether the student has passed or failed.
7. Display the student's complete result.

### Grade Criteria

* 80% and above → A
* 70%–79% → B
* 60%–69% → C
* 50%–59% → D
* Below 50% → F

### Concepts Used

* Variables
* Data Types
* User Input
* Arithmetic Operators
* Comparison Operators
* Assignment Operators
* If-Else Statements
* Console Output
