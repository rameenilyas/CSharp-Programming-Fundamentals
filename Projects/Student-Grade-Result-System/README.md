


# Student Grade & Result System

## Project Description

A C# console application that takes student information and marks as input and determines the student's grade and result.

## Concepts Used

* `if`
* `if-else`
* `else if`
* Nested `if`
* `switch`
* Variables
* User Input
* Output

## Features

* Takes student name as input
* Takes marks as input
* Calculates grade
* Determines Pass or Fail
* Uses decision-making statements
* Displays the final student result

## Grade Criteria

| Marks    | Grade |
| -------- | ----- |
| 80–100   | A     |
| 70–79    | B     |
| 60–69    | C     |
| 50–59    | D     |
| Below 50 | F     |

## Project Goal

The goal of this project is to practice C# decision-making statements by building a simple student result system.
